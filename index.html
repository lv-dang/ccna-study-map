🧭 How to read CCNA questions

"by default"Think factory settings: HSRP no preempt, VRRP preempt, LLDP off, CDP on, port security shutdown, OSPF priority 1, MAC aging 300 s. "most likely cause"Pick the one fault that explains all symptoms: collisions + CRC = duplex; 2-Way between DROTHERs = normal. "standard / open"VRRP, LLDP, LACP, 802.1X, RADIUS. Not HSRP, GLBP, CDP, PAgP, TACACS+. "Choose two"Both must be true on their own. Eliminate anything with a wrong port, wrong default or wrong layer. Show outputRead the codes first: [AD/metric], O IA / O E2, SU/RU, (s), FWD/BLK, DR/BDR/DROTHER. Labs (sims)Config tasks are usually VLANs, trunks, EtherChannel, static/OSPF, NAT, ACLs, SSH, port security. Save with copy run start if asked.
